Answers the open question *"'Later languages' are never named — name them?"*.

planning work and came from Tatjanizza:

## Full set

Sumerian, Akkadian, Phoenician, Hebrew, Sanskrit, Ancient Greek, Old Norse, Welsh,
Serbian, English.

The message-2 statement names only Sumerian, Akkadian, Hebrew, Sanskrit and Ancient
Greek, then says "later languages continue the movement toward the present". Those later
languages are **Old Norse, Welsh, Serbian and English** — that is the movement it means.

⚠️ Sumerian appears in the statement but not in the meta description or the phrase list.
Worth reconciling.
