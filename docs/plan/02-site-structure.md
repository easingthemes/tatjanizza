# Site structure

Source: [00-raw-messages.md](./00-raw-messages.md), message 1.

## Home `/`

Deliberately minimal:

- Name: **Tatjanizza**
- One good image / album cover
- One sentence: who she is
- The music (player / links to streaming)

Nothing else. Home is not where the story is told.

## Project page — *Two Million Years* / Project Archive

The real document. Contains:

1. **Artist statement**, 500–800 words (see [03-artist-statement.md](./03-artist-statement.md))
2. **Timeline of each song** with original release dates → "zlato za provenance"
3. **Credits / provenance block** (see [04-provenance.md](./04-provenance.md))
4. **Project history — Berlin, 2026** — short section, sober tone
